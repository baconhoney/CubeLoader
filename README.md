# CubeLoader
This is CubeLoader - the main app that controls the LED Cube - version 2, for the V2 LED Cube capable of 24-bit color and ethernet access.

## Docs
- CubeLink protocol: [/docs/CubeLink Specifications.md](/docs/CubeLink%20Specifications.md)
- CubeLoader specs: [/docs/CubeLoader Specifications.md](/docs/CubeLoader%20Specifications.md)

## Usage
Start the app with `python CubeLoader.py`.
